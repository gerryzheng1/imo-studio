# Liquid Desk — complete replacement

Mode: Operate. The user rejected the shipped 2.1 visual world and on 2026-10-19 explicitly requested a complete reset and “极致的 liquid glass”. Existing screenshots are anti-reference, not authority. Preserve the local business engine, saved projects, document generation, defaults, snapshots and scroll memory.

## Direction contract

THESIS: An open, immersive voyage desk. A floating bottom instrument dock and an on-demand document library replace the fixed left outline. The working document has the most space. No permanent sidebar, no simulated OS window, no card dashboard.

OWN-WORLD: Clear convex lenses over an authored aqua / periwinkle / peach fluid field. Bright meniscus rims, dark lower edge, restrained spectral edge separation and real SVG backdrop displacement. Ink and opaque-enough table cells remain readable. Every control, form, menu, sheet and dialog uses this family; light and dark are complete.

STORY: Choose a port in the floating route capsule. Open the file library or jump from the current document selector. Work in a broad glass sheet. Save or generate from the persistent dock. Common data, defaults and settings remain easy to find without filling the editing canvas.

FIRST VIEWPORT: A compact project masthead at the top; detached port capsule below. A large central floating editing sheet, unobstructed by permanent navigation. A centered bottom dock with voyage / files / common data / output and save / generate. The library is a nonmodal, keyboard-dismissable popover above the dock. First-use composition is a large left welcome and a tall right convex-glass port intake, with actual add/open actions.

FORM: User-pinned replacement, code-led implementation. Seven grounded structures considered: (1) detached instrument dock + document library, (2) flight-strip dispatch, (3) bridge instrument console, (4) customs document folio, (5) transparent light-table overlays, (6) coastal navigation chart, (7) port clearance document rack. Selected #1 for direct task access and room for dense tables, with the layer discipline of #5. The required concept-seed invocation was attempted and blocked by Windows group policy; no seed key, generated card or detector result exists. No approved comp. The explicit user pin governs.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Signature interaction: the document library expands from its dock control into a clear refractive sheet; pointer position moves a bounded specular reflection. Selected port / dock elements feel like a small rounded lens. Page replacement preserves port/document scroll memory.

QUALITY BAR: replacement topology visible at first glance; clear glass materially distinct from frosted flat rectangles; readable small text, contextual port/file identity, useful new-user state, real forms and exports. Verify desktop 1512, actual-user 1280, mobile 390, dark, defaults, stores, file library, snapshot preview. Reduced motion freezes ambient motion; fallback transparency remains readable; no remote resources. Functional coverage includes keyboard library access, focus return, dismiss, no accidental edits, snapshots/defaults, nested scroll axes and output checks.
