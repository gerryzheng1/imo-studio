## 离线、兼容与性能

1. 只需少量本地 CSS；适合在现有构建阶段内联到单 HTML，也适合文件夹版，无需新增运行时依赖、模块导入、CDN 或网络权限。
2. 原文件包含原生 CSS 嵌套（例如 `.box { svg {...} &:before {...} }`）。建议接入时展开选择器，减少旧版船用电脑浏览器差异，不为此引入 Sass。嵌套语法说明见 [MDN CSS nesting](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Nesting/Using)。
3. 背景模糊应在已存在的一个材质实现中统一控制。不要再安装第二套玻璃库、第二个背景画布或额外的常驻动画循环。上游本身不需要动画渲染器。
4. 避免在玻璃祖先施加整体 `opacity`、`filter:contrast(...)` 或 `will-change:opacity`。它们会改变背景采样边界；`backdrop-filter` 只采样到最近的 backdrop root。应调背景颜色的 alpha，而不是降低整个控件的 opacity。[MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)
5. 给不支持背景滤镜的环境提供较实底色；保留文字、焦点、选中和错误状态的对比。桌面 Chrome、Edge 与 1280px / 手机宽度的实际表现应在接入后由主任务验证，本次只读检查没有声称完成性能或跨浏览器渲染测试。
6. 控制表格区域嵌套模糊层数；高光装饰不拦截点击，不进入 Tab 顺序。减少动态效果 / 低负载外观选项应关闭装饰动画，而不是关闭业务反馈。
