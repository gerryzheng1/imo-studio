# 3.2 流程与界面检查

检查基于真实 3.1 页面截图、最终源码和 Chrome / Edge 操作；仅使用演示工程，不读取或覆盖真实工程。未把自动 detector 或原生 Office 打印写为通过。

| 级别 | 原问题与影响 | 修正及验证 |
| --- | --- | --- |
| P1 | 新外壳的单份下载入口丢失，想要一份文件必须逐个取消整包勾选 | 编辑页、输出行、填写预览提供同一受保护单份下载；实际读取 XLSX 验证 |
| P1 | 整包与本港输出范围不够清楚，当前页面只选择本港文件但底部进入多港核对 | 独立“生成本港 ZIP”和“多港批量”，底部显示所选港口数；实测一港／两港不同核对范围 |
| P2 | 切换文件要反复打开文件库 | 文件下拉与上一份／下一份直达实际编辑器，边界按钮禁用；保留原文件库 |
| P2 | 长问题清单占据生成核对窗口 | 先显示两项可定位问题，其他项展开；所有问题保留且可访问 |
| P2 | 核对后整块替换 DOM，键盘焦点和关闭后的原按钮可能丢失 | 保存核对焦点／弹窗滚动；按相同页面上下文恢复重绘后的按钮；真实键盘验证 |
| P2 | 闭合的更多操作区、壳体间距及单份行按钮影响可用空间 | 为更多操作补齐局部样式，闭合时保持同行；收紧桌面壳体，手机单份行操作单独排布 |

本轮保留的优点：离线无外部请求、可读的数据背板、深浅主题、系统偏好、真实模板输出、按港口／文件保留双轴滚动、独立库存和个人物品快照。

`verify_flow32.mjs` 在 Chrome、Edge 共 28 组实际流程检查通过，包含真实十文件基准与单份 XLSX、无关错误不阻挡、整包选项／基准／其他港口不被改写、日期及健康保护、陈旧预览和写入中修改拒绝、手机溢出检查。其他当前回归和最终审查以相应报告为准，不宣称所有环境无 Bug。

独立复核要求的修正已落实：真实船舶／航次错误路由及卫生／物品／病例字段定位、仅在编辑器内回退焦点、可生成数量标签、帮助入口说明。每浏览器 16 条真实报错点击证据见 flow32-recovery-*.json；复核裁决以 flow32-finish-review.md 最新条目为准。
