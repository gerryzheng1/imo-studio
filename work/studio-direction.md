# Document workspace — replacement direction

Mode: Operate. Web, offline Windows desktop first; mobile usable for quick review.

The rejected work used a colored wallpaper, decorative window frame, two sidebars, four parent tabs and another segmented child row. None is authority. The user's final brief says to forget all earlier frameworks and start over, while retaining genuine business capabilities. The former Apple reference is material guidance, not permission to copy irrelevant iOS widgets.

FIRST VIEWPORT: an unobstructed white working document on a pearl canvas; one narrow file outline, a horizontal route of named port stops, then the title of the exact file being edited. Choose the port, then the file. The interface shows operational data in its first viewport rather than marketing cards or a simulated operating system window. Original table data has enough contrast and generous row spacing without sacrificing a desktop work area.

Signature interaction: switching a port replaces only the document context, preserving the file and each port's own table scroll. Repeated declarations use one quiet reusable-default strip, not four large dashboards. Snapshot matching shows names and counts before restoration. Frosted material is restricted to route/app navigation and dialogs, where it separates foreground controls from scrollable content. Editing surfaces remain opaque and legible.

Form: one file outline, no second sidebar, no four-category parent tabs. The itinerary is horizontal. Shared archives and default settings are separated from per-port files. Font: native system UI face, because this is an operating surface. Color: cool pearl / white, ink text, single restrained blue action color. Dark theme uses neutral slate. Rasters are unnecessary; icons are consistent 24px stroke geometry.

QUALITY BAR: all real editors and generation actions function offline; no page-wide horizontal overflow at 390px (tables scroll internally); keyboard focus visible; body/secondary text contrast 4.5:1 except intentionally faint author credit; no hidden essential mobile actions; no fabricated declarations; original Excel behaviors retained. Required evidence: 1512×1050 effects, defaults and stores; 1280×800 active editor; 390×844 mobile; 1512×1050 dark. No approved image comp. Code-led replacement.
